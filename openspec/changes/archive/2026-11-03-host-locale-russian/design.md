# Design

## Context

См. `proposal.md`. Страница настроек плагина уже отдаёт словарь `pet.config` в `ctx.locale` (`dsh-pet/src/client/settings/locales/`), и среди языков есть `ru`. Остальной интерфейс — китайские литералы: меню в `shared/menu/tree.ts`, чат в `client/chat/`, пузыри в `shared/whisper.ts`, лоток в `runtime/electron-helper/main/tray.js`, автономная страница в `standalone/settings-page/`. Хост в `inject` язык не объявляет. Настольный помощник и автономный процесс сами `ctx.locale` не видят.

Снимок `/state` — это `sections` и `pets` из листьев `{ counter, data }`. Незнакомую секцию старый клиент пропускает.

Кадры в дереве репозитория не лежат. Категория `文字` в `assets/config.jsonc` помечена `noMirror`, потому что на ролике есть слова: `是啊，吃什么` и `深度思考碎碎念`. У части мемов описание прямо цитирует надпись на картинке. Значки уведомлений в промпте заданы без текста.

Требования — `specs/pet-locale/spec.md`.

## Goals / Non-Goals

**Goals:**

- Один идентификатор языка хоста питает и уже существующие настройки, и новые поверхности.
- Настольный помощник и автономная страница узнают этот идентификатор из снимка состояния, без второго источника.
- Русский кадр лежит рядом с исходным и подменяется только по запросу. Ключи конфига не меняются.

**Non-Goals:**

- Словари английского, японского и остальных языков хоста для меню и чата. Пока язык не `ru`, остаются сегодняшние китайские строки.
- Правка `pet.config` и пересборка `ru.ts` настроек.
- Смена сохранённого голоса TTS. Китайский голос по-прежнему говорит то, что записано в конфиге; подписи выбора голоса уже переведены настройками.
- Перерисовка роликов без слов, значков уведомлений, `Zzz` и многоточия.
- Перевод комментариев, журналов и кодов ошибок.
- Коммит `step01/`–`step04/` и `video/*.mp4`.

## Decisions

### Язык публикуется секцией снимка

Клиент, у которого уже есть `ctx.locale`, читает активный id тем способом, который этот сервис отдаёт словарю настроек. Если отдельного чтения id в типах установленного DSH нет, клиент регистрирует служебный ключ, чьё значение в каждом из восьми словарей равно id языка, и читает его через `bind`. При старте и при смене id клиент сообщает его хосту.

Хост пишет лист `sections.locale` с `data: { id }`. Это то же дерево листьев, новое поле верхнего уровня в JSON не появляется. Нет секции, id пустой или неизвестный — поверхности ведут себя как при языке не `ru`.

Автономная страница один раз читает `/state` при открытии и ещё раз, когда вкладка снова становится видимой. Процесс без хоста секции не получает и остаётся на китайском HTML.

Альтернатива — внедрить `locale` в `inject` хоста. Её не берём: хост этот сервис не ждёт, а клиент его уже использует. Альтернатива — query-параметр только у страницы настроек. Её не берём: лоток и меню рабочего стола ходят в тот же снимок.

### Один каталог поверхностей, не словарь настроек

Фиксированные строки меню, чата, пузырей, дел, уведомлений, лотка и автономной страницы живут в одном каталоге рядом с общим кодом, чтобы его видел и браузер, и `shared-core` помощника. Китайский набор — источник ключей, русский — полная запись тех же ключей. Проверка та же, что у настроек: одинаковые ключи, одинаковые плейсхолдеры, в русском нет иероглифов.

Клиент при `ru` берёт русский набор, иначе китайский. В `ctx.locale.register` этот каталог не кладётся: настройки остаются в `pet.config`, иначе появятся два хозяина одних и тех же строк.

Подпись встроенного действия и категории берётся из каталога по id. Нет ключа — на экране сам id. Поле `anim` и ключ мема не переписываются.

Сторонний пункт меню каталог не трогает.

### Встроенный текст отделяется от текста человека сравнением с пакетом

Русские строки имени, истории и времени подставляются в системный промпт только при `ru`, вместе с одной фразой «отвечай по-русски». Та же просьба повторяется в конце реплики пользователя: китайская история и списки картинок иначе задают язык ответа. Инструкции бормотания, картинок и действий при `ru` тоже русские; имена действий и ключи мемов не переводятся, метки `[动作:]` и `[图:]` остаются.

`whisperPrompt`, `workStatusTexts` и описания встроенных мемов заменяются русским набором только когда эффективное значение целиком совпало с пакетным `assets/config.jsonc`. Любое отличие — текст человека, его не трогаем. Так не появляется второе поле конфига.

Лунный календарь не копируется. Переводятся уже собранные клише времени; расчёт даты остаётся одним.

### Русский кадр — соседний файл, исходный URL не меняет байты

Для id из списка ниже при `ru` адрес просит `ru/<то же имя и расширение>` внутри той же цепочки каталогов, что и сейчас у `/thumb` и `/pic/memes`. Запрос без этого префикса всегда отдаёт исходный файл. Если русского файла нет, ответ на русский адрес — исходный файл и успешный статус, чтобы плеер не ломался.

Список после сверки кадров релиза. Из исходного набора ничего не вычеркнуто: на всех этих кадрах есть читаемые слова. Добавлены кадры, где слова нашлись вне списка. `可爱` без слов, поэтому его нет. Чистый `Zzz`, вопросительный знак и нечитаемый код на экране ноутбука словами не считаются.

- ролики: `是啊，吃什么`, `深度思考碎碎念`, `写福字`, `收红包`;
- мемы: `大烧货`, `先养着吧`, `哦鲸鲸`, `除了调情没啥用`, `我不更新你们用什么`, `哪来的电脑病毒`, `大师这个区是什么意思`, `就骚了怎么滴吧`, `完蛋了把黄油删了`, `就一碗`, `鱼片有资源吗`, `假如给我三天多模态`, `Ciallo`, `吃白饭的大肥鱼`, `大的要来啦`, `大的药来了`, `要不直接骂他`, `死掉了`, `深度睡眠`, `吃饱饱摸肚子`, `誓死践行开源精神`, `电死你`, `token给妈妈保管`, `厉害了我的鲸`, `压力一只大肥鱼`, `黎曼猜想没证明喵`.

Текст на русском кадре короткий и сидит в той же плашке. Промежуточные файлы пайплайна не коммитятся.

Альтернатива — подменять файл внутри старого URL по секции `locale`. Её не берём: один URL начал бы отдавать разные байты, и кэш рабочего стола показал бы не тот язык.

### Распознавание речи

При `ru` клиентский голосовой ввод передаёт уже существующее необязательное поле языка со значением русского. При любом другом языке поле по-прежнему не отправляется. Голос синтеза не переключается.

### Контракт

Новая секция `locale` описывается в коде разбора `/state`, в `openapi.yaml` и в `API.md`. Старый клиент её игнорирует. Иных полей запроса, кроме уже разрешённого языка распознавания, нет.

## Risks / Trade-offs

- [Голос TTS остаётся китайским и читает русскую реплику] → в этой задаче голос не меняем; человек выбирает русский голос в уже переведённых настройках.
- [Исходных PNG/WebM нет в дереве, список мемов может сузиться после просмотра] → код выбирает русский файл только для id из итогового списка и всегда умеет отдать исходный.
- [У `ctx.locale` может не быть отдельного getter] → запасной путь через служебный ключ словаря, без нового API хоста.
- [Автономная страница на миг показывает китайский HTML] → подмена после чтения `/state`; без секции китайский и есть нужный результат.
- [Своя китайская персона перебьёт просьбу отвечать по-русски] → свой `whisperPrompt` не переписывается; пакетный заменяется только при полном совпадении.
- [Праздничные клише времени — большой набор строк] → переводится только готовая фраза, календарь один.

## Migration Plan

Поле конфига не добавляется, миграции файлов пользователя нет. Секция `locale` для старых клиентов лишняя и безвредная. Откат — перестать сообщать `ru` и не класть русские кадры: исходные URL и китайский каталог остаются рабочими.

Русские ролики и мемы поставляются тем же каналом, что и остальные кадры (релиз ассетов), а не промежуточными каталогами репозитория.

# dsh-pet v0.4.5

## 📦 安装 / 更新

```bash
dsh plugin --profile web add dsh-pet@0.4.5
```

> 显式指定版本安装，避免本地缓存命中旧版。桌面端把 `--profile web` 换成 `--profile desktop`。
> 不想装 DSH 也能用：Release 附件里的 `dsh-pet-win-x64.zip` 解压双击即可运行（Windows x64）。

## ✨ 新功能

### 🍚 「吃白饭」变成内置玩法

- 右键菜单点「吃白饭」，桌宠会跑到屏幕底部等开饭、追饭、吃碗饭或饭团，米饭和分数会出现在屏幕上。
- 动作用的是配置里的动画名，换了素材也不会卡住。

### 💬 侧栏对话支持 8 种语言

- 跟随 DSH 的语言设置：简中 / 英 / 日 / 西 / 法 / 德 / 俄 / 葡。
- 标签页标题、按钮、输入框提示、确认弹窗、时间显示都跟着语言变。
- 这次只覆盖右侧栏的对话；右键菜单、托盘和气泡仍是中文。

### 🧠 第三方可以接管桌宠的记忆

- 装了提供记忆能力的插件（例如接自己的知识库），可以替代桌宠默认的对话记忆方式；没装时行为完全不变。
- 想自己写这类插件，接入方式见 `CORDIS-API.md`。

## 🐛 修复

### 桌面端

- **插件市场装不上、更新必失败**：以前桌宠启动时会占用 DSH 依赖目录里的 Electron，插件市场更新时删不掉那个目录，只能报错。现在桌宠只用自己下载的那份，插件市场恢复。（#297）
- **Wayland 下桌面模式不好用**：桌宠不能置顶、会挡住点击、也跑不出窗口。现在会自动切到兼容模式；纯 Wayland 环境会提示该功能不可用。（#294）

### 外观

- **页面莫名多出一条滚动条**：桌宠给图片透明效果加的一层隐藏元素把页面撑高约一行，顶部标签条被顶出视野；已修正。（#291 #292）

### 其他

- **「吃白饭」看起来原地踏步**：看门狗按写死的素材名判断动画是否在播，素材改名后会每 0.4 秒重开一次接力；现在按配置里的动画名判断。

## 🔌 兼容性

- 已在 DSH `0.2.1-rc.3` / `0.2.2-alpha.2` / `0.2.2-rc.1` 上验证通过；安装方式与配置格式没有变化。

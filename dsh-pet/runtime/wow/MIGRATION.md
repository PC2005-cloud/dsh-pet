# dsh-pet 魔兽陪伴

迁移日期：2026-11-05。复用 dsh-pet 的桌面宠物、动画、聊天、记忆和语音，将魔兽业务接入同一宿主，无需启动 AIRI。

## 已接入

| 功能       | 行为                                                                                                                                                                                             |
| ---------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| 游戏连接   | 设置 → 魔兽伙伴。正式服与无限服有独立桥接、校准和档案，新安装默认关闭连接。                                                                                                                      |
| 角色实况   | 等级、职业、阵营、地图与坐标、战斗/生死状态及采集诊断；过期数据不充当当前位置。                                                                                                                  |
| 金币账本   | 账号命名、各角色余额、累计收入/支出与净额，按插件计数去重并保留精确铜币数。                                                                                                                      |
| 装备与升级 | 获取历史、比较结论、换装摘要、配装与升级记录，更换装备仍在游戏内确认。                                                                                                                           |
| 事件提醒   | 升级、区域、生死、日历、团队增益及装备消息使用中文/英文模板；持续一分钟非战斗空闲时可说一句固定陪伴短句，需宠物启用自动碎碎念；遵守静音、冷却、战斗安静与宠物睡眠/占用状态。固定通知不调用模型。 |
| 魔兽知识   | 按正式服、无限服、怀旧服区分通用事实与语言社区缩写/热梗；DZ 等缩写按版本和语言检索，单轮聊天加入相关观测和历史。                                                                                 |
| 插件管理   | CurseForge 检索、版本选择、推荐、依赖安装；保留游戏目录校验、ZIP 校验、备份与安装收据。API 密钥由 Windows 当前用户 DPAPI 加密，不经状态接口返回。                                                |
| 快捷启动   | 配置战网或对应版本启动程序时校验文件、签名、产品信息与目录，启动前再次校验。                                                                                                                     |
| 宏导入     | 仅用户主动提交后向已验证的唯一游戏窗口导入，通过 WoWMacroImport 插件回执确认；不会代替用户执行宏。                                                                                               |
| 主动截图   | 明确请求看地形、找 NPC、查看任务画面或 `/look` 时截取已验证的游戏窗口；默认关闭，图片仅保留在本次请求内。                                                                                        |
| 旧档案导入 | 输入旧 AIRI 用户数据目录，仅导入金币、装备、升级、比较和配装文件；整批校验后替换并备份目标旧文件。                                                                                               |

怀旧服提供知识、插件工具、启动和截图。本次源码没有怀旧服实况采集协议，因此没有怀旧服实况。

## 运行与配置

“设置 → 魔兽陪伴 → 陪伴形象”默认使用 dsh-pet 原有形象。安装自定义宠物包后，可在同一选择器中预览并应用；切换会隐藏前一个陪伴实例并显示选中的实例，聊天默认对象和魔兽通知一同切换，各自的动画、人设与历史保留。其它多开宠物不受影响。选择原有形象并应用即可恢复默认，重启后保留已保存的选择。

聊天也能触发工具：主动要求推荐插件会查询 CurseForge 并显示可安装的推荐卡；主动要求生成或导入宏时，校验一个宏并最多导入一次。只有游戏插件的 `saved` 回执确认成功。引用、例句、否定和游戏事件不会授权工具操作。

```powershell
cd E:\PythonWorkspace\dsh-pet\dsh-pet
pnpm install
pnpm run build
pnpm run standalone
# Electron 桌面应用：
pnpm run start:app
```

通过独立模式输出的认证链接打开设置 → 魔兽陪伴；DSH 插件模式提供同名设置分区。沿用既有 AI 配置，截图需要所选服务和模型支持图像输入。

桥接需要 Windows 和 Python 3.10+，仅使用标准库，无需 pip。自动寻找 Python，Electron 包从 `resources/wow-companion-bridge` 运行脚本，插件和 CLI 从 `runtime/wow/WoWCompanionBridge` 读取。打包包含桥接脚本，不包含 Python 解释器。

将本目录对应插件文件夹复制到游戏 `Interface/AddOns`：正式服用 `WoWMapCompanion`，无限服用 `WoWForeverCompanion`；宏导入另需 `WoWMacroImport`。完整重启游戏后启用对应连接，按插件 README 校准屏幕传输码。正式服端口为 18765，无限服为 18766。

数据保存在 dsh-pet 既有用户目录的 `wow/` 子目录（通常为 DSH_HOME 下的 `dsh-pet/wow`）。退出时刷新账本并停止宿主拥有的桥接进程，外部启动的桥接不会被结束。历史导入不会复制聊天密钥、截图或宠物配置，备份位于 `wow/import-backups/`。

## 截图限制

可辅助解释地形、NPC 寻找、任务文字、地图标识与界面提示。截图不能确定的通行性、任务阶段和隐藏机制，应明确不确定并提供游戏内核实步骤。截图失败会报告没有取得画面。

独立模式已为现有 OpenAI 兼容协议和 Anthropic 协议接通内存图像。当前 DSH 内核图片接口只提供持久附件，插件模式暂不支持这条临时图片通道，会明确报错。普通聊天、事件提醒、碎碎念和历史回放不触发截图。

## 迁移边界

依据 `wow-airi-companion` 提交 `654f6b5` 的实际源码：正式服插件/桥接 2.19.0，无限服插件 1.17.0。上游 README 所述 2.25.0 位于另一开发目录，本机未取得源码；背包/银行 SQLite、关系记忆等摘要中的新功能不能视为已迁入。

保留 dsh-pet 现有渲染方式和用户自定义宠物。此次未移植 AIRI 的 Live2D/Cubism 渲染器，旧 `.model3.json` 不能直接作为 dsh-pet 视频宠物导入。

平台适配差异：工具页目前提供简体中文和英文；启动程序路径手填；角色上下文按所选或当前问题明确的游戏版本决定，不仲裁不同版本最近登录的角色。装备提醒保留游戏内确认，不复刻 AIRI 桌面的接受/拒绝阶段。

桥接的 DB2 只读查询底层脚本一并保留；源仓库桌面端未接入该协议，目标也没有提供桌面选库/查询入口。

自动验证使用临时目录、模拟桥接/窗口、离线页面和模型传输替身。真实游戏仍需验收屏幕码校准、图形驱动的窗口截图支持、签名程序启动、宏插件回执、CurseForge 和视觉模型。验证不启动游戏、不向游戏输入宏、不调用付费模型。

## API 与来源

复用宿主的路由和访问控制：

- `GET /dsh-pet-7340/wow/state`：两个实况档案、偏好、启动器、截图和插件设置，不含密钥。
- `POST /dsh-pet-7340/wow/action`：`{action, game?, data?}`，保留领域返回值中的 `ok`/`code`/`error`。
- 动作：`preferences.save`、`settings.save`、`capture.save`、`demo`、`account.rename`、`macro.import`、`launcher.save`、`launcher.launch`、`screen.save`、`knowledge.search`、`history.import`。
- 插件动作：`addons.settings.save`、`addons.installed`、`addons.metadata`、`addons.search`、`addons.files`、`addons.install`、`addons.recommend`、`addons.installRecommendation`。

实况/账本/宏的 `game` 仅支持 `retail` 和 `forever`；其余工具保留 `classic`。不能通过动作选择任意执行命令、桥接 URL 或端口。

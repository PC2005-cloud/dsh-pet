# 魔兽陪伴精灵 · 宏导入

实时传输与宏导入回执的关系见 [游戏插件与 AIRI 通信说明](../wow-addon-airi-communication.md)。

## 使用

安装 `WoWMacroImport` 文件夹到对应客户端的 `Interface/AddOns`。
进入游戏后输入 `/import-marco`，在文本框中输入或粘贴宏。
点击“校验并导入”，或在文本框内按 `Ctrl+Enter`。
保存成功后，打开 `/macro`，将角色宏 **WCP Import** 拖到动作条。
`/import-macro` 是同一命令的别名。

该插件仅保存宏，不执行宏。手动导入不依赖陪伴精灵或遥测插件。

## 校验与保存

- 去除首尾空白，将 Windows 换行转为游戏换行。
- 正文不能为空，最多 255 UTF-8 字节。超长内容直接拒绝，不截断。
- 拒绝控制字符。每个非空行必须使用当前客户端已注册的斜杠命令，或 `#show` / `#showtooltip`。
- 客户端提供 `loadstring` 时，对 `/run` 和 `/script` 的单行 Lua 做语法编译检查，不调用编译结果。
- 校验不能证明技能已学会、物品存在、条件正确或宏运行效果符合预期。
- 保存前再次检查战斗状态和角色宏容量。
- 使用角色专用槽位。只更新本插件保存且内容未被其他工具修改的同名宏。
- 同名冲突时拒绝覆盖。玩家可以先重命名自己的同名宏。
- 保存后调用游戏 API 读回正文。只有内容一致才报告成功。

## 陪伴精灵自动导入

在聊天中请求：“帮我写一个选中某 NPC 的宏并导入游戏。”
聊天模型须支持工具调用，使用 `wow_import_macro` 提交宏正文和游戏版本。
正式服需 WoWMapCompanion 2.13.0，无限服需 WoWForeverCompanion 1.10.0，本机桥接需 2.13.0。

桌面端验证唯一的对应游戏窗口，将宏写入剪贴板，并尝试将游戏切到前台。
根据新鲜传输码判断战斗状态。战斗中最多等待 90 秒，脱战后开始输入。
自动流程打开聊天框，输入 `/import-marco` 和本次编号，再粘贴宏并按 `Ctrl+Enter` 保存。
插件报告输入框焦点、内容摘要和保存结果。自动流程等待对应回执后才继续。

流程开始后，保持游戏在前台。切换窗口、按 Esc、关闭输入框、重新进入战斗、角色切换或采集失效都会中止。
失败后不自动重试。宏仍可通过剪贴板手动导入。剪贴板将保留生成的宏文本。
模拟输入被操作系统拒绝时，返回失败，不提升权限。

## 验证

在 `WoWCompanionBridge` 目录执行 `python -m unittest test_macro_import -v`。
测试使用真实 Lua 5.1 执行插件代码，并检查两版遥测帧和桌面流程。
自动化测试不替代真实游戏 UI、输入法、缩放与焦点的实机验收。

2026-10-29 验证结果：桥接 177 项、正式服插件 165 项、无限服插件 164 项及桌面相关 38 项测试通过；桌面类型检查、构建和仓库 lint 通过（lint 保留既有警告）。根目录类型检查因既有 MediaPipe 模块缺少依赖而未通过。当前未运行魔兽客户端，尚未验证真实游戏中的粘贴和保存。

实机验收步骤：

1. 重启游戏与陪伴精灵，启用宏导入插件及对应版本的传输插件。
2. 输入 `/import-marco`，粘贴 `/targetexact 测试NPC`，点击“校验并导入”；在 `/macro` 中确认 `WCP Import` 的正文。
3. 开启陪伴连接并确认角色数据实时更新，在聊天中请求写宏并导入，检查游戏中的保存提示和宏正文。
4. 在战斗中提出请求，确认脱战前不输入；导入期间切换窗口，确认流程中止并报告失败。

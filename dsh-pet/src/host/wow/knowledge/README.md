# 魔兽陪伴知识库

本目录保存可随应用发布的本地知识。聊天按当前消息检索相关条目，不把整个知识库放入提示词，也不调用额外的模型服务。

## 目录与范围

```text
data/
  shared/
    general.json          # 三个版本共用的基础概念
    locales/zh-CN.json    # 中文社区缩写、译法与梗
    locales/en.json       # 英文社区缩写与梗
  retail/
    general.json          # 正式服专属知识
    locales/zh-CN.json
  forever/
    general.json          # 魔兽世界：无限专属知识
  classic/
    general.json          # 怀旧服知识，具体分支另作限定
    locales/zh-CN.json
```

各版本同时使用 `shared` 中的条目。专属规则只在对应版本范围内检索。
`general.json` 的 `und` 标签表示不限定语言社区，不表示正文必须使用某一种语言。
模型按对话语言解释通用知识。社区条目按消息语境筛选，不会仅因界面使用英语就将中文缩写解释成英语。

首批中文社区内容按 `zh-CN` 管理，暂不分别建模台湾、香港及其他中文社区的用法差异。
日语、韩语等社区尚无专属条目，当前仅能使用通用知识。

`forever` 对应本项目的《魔兽世界：无限》，不是私服或任意魔改服的统称。
`classic` 是怀旧服知识分类，不代表所有怀旧分支机制相同。
涉及天赋、装备、等级上限或副本规则时，先明确分支、资料片和补丁。
知识库支持怀旧服聊天，不会新增怀旧服实时采集协议或插件。

## 聊天中的选择顺序

1. 用户明确说出版本时，使用该版本。比较多个版本时，分别标记每条知识的版本。
2. 用户没有明确版本时，参考当前可用的游戏角色状态。
3. 无法确定版本时，只使用 `shared` 条目。离线聊天仍能理解 `DZ` 等通用缩写。
4. 消息中的语言和明确的社区称谓优先于界面语言。只有短缩写缺少语言线索时，使用界面语言。
5. 优先匹配别名，其次匹配条目标签。默认最多选取 6 条，提示词最多 6500 字符。

`DZ` 按中文社区条目解释为盗贼。`SM`、`DK` 等词保留歧义说明。
英文缩写按词边界匹配，不把 `ADZ123` 中的一段字符识别成 `DZ`。
全角字母、大小写经过统一处理。原始用户消息不会改写。

普通聊天按请求生成临时知识片段，不把检索结果写入长期上下文。
游戏事件使用 `../notifications.ts` 中的中英文固定模板，无需调用模型。知识检索用于用户聊天和已有碎碎念上下文。

## 条目格式与来源

每个 JSON 文件包含条目数组。`schema.ts` 校验格式，`catalog.ts` 注册文件并检查 ID 重复。

| 字段                    | 含义                                                  |
| ----------------------- | ----------------------------------------------------- |
| `id`                    | 全库唯一的小写连字符 ID                               |
| `kind`                  | `fact` 通识或机制、`abbreviation` 缩写、`meme` 社区梗 |
| `title`                 | 条目名称                                              |
| `aliases`               | 用户可能直接使用的词语，避免过宽的单字别名            |
| `text`                  | 事实、释义或语义说明                                  |
| `usage`                 | 版本限制、歧义、适用互动场景和出处边界                |
| `tags`                  | 可选的相关话题检索词                                  |
| `provenance.status`     | 证据类型，见下表                                      |
| `provenance.sources`    | 来源名称与网页 URL 或仓库相对路径                     |
| `provenance.reviewedAt` | 内容核对日期，不代表事实永久有效                      |

| 证据类型       | 使用原则                                             |
| -------------- | ---------------------------------------------------- |
| `verified`     | 有可核对来源的事实，仍遵守条目中的版本与时点限制     |
| `community`    | 社区用语或译法，不当作官方设定、官方字幕或流行度统计 |
| `user-example` | 用户给出的互动示例，允许收录但不捏造原作出处         |
| `project`      | 来自本项目实现或说明的事实，不当作游戏官方规则       |

“部落都是废物”和“你们这是自寻死路”可用于理解梗或合适的虚构角色互动。
归属未确认时，不指定台词说话人或声称核验过原始字幕。
原创互动示例必须标为原创，不能冒充游戏台词。
阵营调侃仅针对虚构阵营，不针对真实玩家。用户不喜欢时停止调侃。
每次回答最多自然使用一个梗，严肃求助无需插梗，也避免连续重复同一句。

## 扩充与维护

1. 将内容放入对应版本的 `general.json` 或 `locales/<社区>.json`。
2. 为每条内容添加来源、核对日期和适用范围。
3. 对未核实的社区说法使用对应证据类型，不补写猜测的出处。
4. 新增文件或语言时，同时更新 `catalog.ts`、语言筛选规则及测试。
5. 对新缩写添加命中、歧义和误匹配案例。
6. 游戏更新后重新核对机制条目。不要将本库当作实时攻略或当前版本数值数据库。

项目来源中的仓库相对路径指向原始 `wow-airi-companion` 仓库；它们是内容溯源，不是 dsh-pet 的运行时文件路径。
本库保留独立的检索条目和出处边界，不将研究资料中的所有句子直接当作可播放台词。

在 dsh-pet 包目录运行：

```sh
node --experimental-strip-types --import ./scripts/test-register.mjs --test src/host/wow/knowledge/index.test.ts
```

检索和测试都不调用模型或联网获取知识。

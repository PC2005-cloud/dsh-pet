# 群聊人设（6 只 AI 娘桌宠）

本文件是作者为本机桌宠配置的 `whisperPrompt` 人设（对应 `pets[].id` 的 `whisperPrompt` 字段）。
配合 `pet-chat-race.js`（同目录）可跑一桌「AI 娘抢答群聊」。

每条人设 = 拟人化形象 + 性格 + 说话风格 + 群聊定位。粘贴到对应宠物的 `whisperPrompt` 即可。

## 使用说明

- 每条人设对应一个桌宠实例，写在它的 `whisperPrompt` 里（实例级配置，或 main-config 的 `pets[].whisperPrompt`）。
- 想让某只宠不参与群聊，把它的 id 从 `pet-chat-race.js` 的 `PETS` 数组里去掉即可。
- 回复会统一经过 `tidyReplyText`（`src/host/persona.ts`）：剥离 emoji/颜文字、硬截 20 字。
